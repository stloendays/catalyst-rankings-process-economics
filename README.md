# Process economics reorder catalyst rankings across computed and published catalysts

Code and data for the paper. Every number, figure and Supplementary Table of the paper is generated from the files in
this repository.

The analysis propagates catalyst properties forward through kinetics, candidate-specific process optimization and a
catalyst-responsive cost objective, and backward from an economic target to the catalyst property it requires. It
covers ammonia synthesis (15 metals, 1,796 bimetallic and pure-metal surfaces, measured Fe/Ru/Co/Ni catalysts),
CO₂ hydrogenation to methanol (Re/TiO₂ case and published comparisons) and Au/TiO₂ CO oxidation as a control.

## Layout

| Folder | Contents |
|---|---|
| `data/` | model inputs: methanol recycle–economics model (`data/meoh/meoh_general_model.py`), Au/TiO₂ control data, frozen headline and registry tables |
| `provenance/nh3_final_1_1/`, `provenance/discover_v1/source_harness/` | frozen ammonia process–economics harness (`harness_core.py`), its inputs and frozen outputs, with SHA-256 manifests (`SOURCE_MANIFEST.json`) |
| `controls/` | Au/TiO₂ rank-preservation control |
| `agent/` | literature-extraction and screening code (methanol `agent/extraction/`, ammonia `agent/nh3_field/`, `agent/nh3_supported/`, Au `agent/au/`), extracted records (`out/`) and accuracy scoring (`eval/`) |
| `analysis/` | one folder per analysis, each with a README stating inputs, method and outputs |
| `figures/` | figure renderers and rendered figures: main figures in `figures/composite/`, Extended Data in `figures/extended_data/` |
| `source_data/` | Source Data workbook for every figure (see `source_data/README.md`) |
| `docs/SI_TABLES.md` | Supplementary Tables 1–6, generated by `tools/build_si_tables.py` |
| `tools/` | builders for Source Data and Supplementary Tables, and comparison helpers |

## Environment

Python 3.12 with the packages in `requirements.txt` (plus `pyyaml`). The ammonia analyses need the harness root: the
frozen response-surface cache is not distributed (it is regenerable); `analysis/nh3_actual_ru_params_2026_10_07/build_harness_root.py`
builds a harness root from `provenance/` and computes the response columns the analyses read. Set `NH3_HARNESS` to that
root. The structure renders of the main figures use OVITO 3.16.

```bash
pip install -r requirements.txt pyyaml
python analysis/meoh_literature_inversion_2026_10_05/run_literature_inversion.py   # methanol field result
python analysis/verify_2026_10_08/errata_adjudication.py                           # Supplementary Table 6 inputs
python tools/build_si_tables.py                                                    # docs/SI_TABLES.md
python tools/build_source_data.py                                                  # source_data/*.xlsx
```

## Data from other sources

- The publications from which catalyst data were extracted are cited in Supplementary Tables 1 and 2; their PDFs and
  Supporting Information are not redistributed. Extracted values carry their table, figure and page locators.
- TheMeCat v1 (Toldy et al., *Sci. Data* 2026, CC BY 4.0): the columns used for scoring are in
  `analysis/verify_2026_10_08/themecat_v1_subset.csv`.
- Bimetallic adsorption energies: Mamun et al., *Sci. Data* 2019, retrieved from Catalysis-Hub.
- Metal prices beyond the model metals: USGS Mineral Commodity Summaries 2026.
